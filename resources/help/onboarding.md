When someone joins or leaves, a **checklist** makes sure nothing is missed.

## How it works

- Each employment type has an onboarding and an offboarding template.
- Each item has an **owner** (HR, IT, the line manager or finance) and a **due date** counted from the start date (onboarding) or leaving date (offboarding).
- Overdue items are marked in red.

Example onboarding items: contract signed, right to work check recorded, bank details received by payroll, accounts created, laptop issued, induction booked. Offboarding: notice recorded, handover plan, final pay confirmed, exit interview, equipment returned, accounts disabled.

## Starting a checklist (HR)

**People › Onboarding › Start a checklist**: choose the person and Onboarding or Offboarding. For offboarding, set their leaving date on their profile first. The line manager is told when items are theirs.

## Ticking items off

Tick an item when it is done. You can tick items you own: HR can tick anything; IT items need an administrator; finance items need finance; line manager items need the person’s line manager. Untick if it was ticked by mistake. The checklist finishes when every item is done.

HR’s dashboard shows how many items are done and how many are overdue.
