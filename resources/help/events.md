An event is a job for a client, from the first enquiry to the final reconciliation. Each has a code such as **EV-26114**.

## Stages

| Stage | Means |
|---|---|
| Enquiry | A client has asked |
| Proposal sent | We have pitched |
| Confirmed | Won. Hive adds the standard task list for the event type |
| Pre-production | Planning and booking |
| Live | On site |
| Wrap | Finished; closing out costs |
| Reconciled | Every cost is in and agreed |
| Closed | Done |
| Lost / Cancelled | Didn’t go ahead. Cancelling releases every booking and tells the crew |

Move an event with the **Move to…** button on its page. Some moves check first: an event can’t be reconciled with invoices still open or in dispute, for example, and Hive tells you what is blocking it. Every move is logged with who and when, and the producer and event team are told.

## Adding and editing

Producers and the operations director can add events (**Events** › **New event**) and edit details: client, venue, dates, phases (travel, build, rehearsal, live, breakdown), team and the client fee.

## The tabs on an event

- **Overview**: details, phases, team, contract and stage history.
- **Tasks**: the task list, with owners and due dates. Tick tasks off as you go.
- **Crew and resourcing**: crew calls and bookings. See [Crew calls and booking](/help/crew-calls).
- **Travel**: flights, trains and hotels. See [Travel and accommodation](/help/travel).
- **Budget**, **Purchase orders**, **Invoices**: the money, for people with budget access. See [Budgets](/help/budgets).
- **Timesheets**: time recorded against the event.
- **Files**: briefs, contracts, plans and floor plans. Files are private; links expire.
- **Activity**: every change to the event.

## Who sees which events

Producers, the operations director, finance and HR see all events. Employees and freelancers see the events they are booked on or part of the team for. Money tabs need budget access.
